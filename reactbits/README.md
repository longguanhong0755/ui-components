# ReactBits Pro — public preview extraction

This directory is an archive of the browser implementation shipped by the public
ReactBits Pro documentation preview. It is intentionally kept out of
`components/` and is **not** wired into the showcase build or the website.

- Source: https://pro.reactbits.dev/docs/components
- Components: 218
- `components/<slug>.js` — extracted entry module, formatted for reading.
  These are compiled browser modules with webpack module references, not the
  original TypeScript source files.
- `chunks/<slug>__<id>.js` — raw public demo chunk exactly as downloaded.
- `catalog.json` — name, category, description, chunk URL and file paths.
- `manifest.json` — full scrape record including failures (none in this run).

Generated by `tools/sync_reactbits.py`; `tools/sync_all_sources.py` runs this and
the original originkit scraper from one command.
